# XMySQL Multimodal and AI Implementation Tracker

> **For agentic workers:** Continue this plan in `codex/mysql-query-compatibility`. Preserve the MySQL query compatibility work already on this branch. Do not claim an item complete from types, examples, or a successful build alone.

**Goal:** Implement the approved v0.8 design as native database behavior on the existing MySQL-compatible branch: one authoritative storage and SQL path for structured and multimodal content, retrieval, evidence-backed model context, and the core MySQL AI feature set.

**Architecture:** Keep row values, content revisions, derivation state, source locators, and index publication under XMySQL's transaction and metadata lifecycle. Reuse the existing BLOB/page, SQL executor, FULLTEXT, permissions, jobs, and driver paths where they satisfy the data contract. Parsers and model calls are replaceable internal workers; they are not independent stores of record.

**Tech Stack:** Existing Go 1.24 module, SQL parser and AST, InnoDB row/BLOB storage, current MySQL protocol and ordinary clients.

**Spec:** `docs/planning/2026-11-25-xmysql-multimodal-ai-agent-plan.md`; `docs/planning/2026-11-25-xmysql-data-access-contract.md`; `docs/planning/2026-11-25-xmysql-mysql-ai-parity-matrix.md`.

## Global Constraints

- Retain all existing XMySQL MySQL query, transaction, protocol, permissions, storage and recovery capabilities.
- One source of truth, one SQL contract; do not add an external vector database or a separate user-facing orchestration service.
- Raw bytes and derived output have explicit identities, revisions, integrity, readiness and source provenance.
- SQL results distinguish not ready, failed, partial, no match, and access denied.
- Ordinary SQL never invokes a model implicitly.
- Model outputs remain derived and link to the exact source revisions and locators.

## Review Focus

- A failed or stale worker must not publish over a newer content revision.
- SQL rollback, concurrent writes, restart, deletion and backup must preserve source/derived consistency.
- Permission checks must cover both source bytes and derived outputs at read time.
- ANN may not silently replace exact retrieval, and vector space/version mismatches must fail.
- A model must receive actual authorized image/audio/video or a declared, located transformation, never only a path or vector.
